JsonValue

A small JSON reader for web service answers.

#include "tagkit/JsonValue.h"

Detailed Description

Just enough JSON to read what MusicBrainz sends back. Reading never fails halfway: a missing key, or an index out of range, gives a null value that reads as an empty string, 0 and false, so lookups can be chained without checking each step:

JsonValue answer;
if (JsonValue::Parse(text, length, answer)) {
    BString title = answer.Get("recordings").At(0).Get("title").String();
}

static bool JsonValue::Parse(const char* text, size_t length, JsonValue& value)

Reads JSON text into a value.

Understands the whole of JSON, including \uXXXX escapes (and pairs of them for characters above U+FFFF), which become UTF-8. Nesting more than 64 levels deep is refused.

Parameters

text
The JSON, as UTF-8.
length
How many bytes of text to read.
value
Receives the result.

Returns

true if the text was valid JSON with nothing but spaces after the value. Otherwise false, and value is left null.
