CoverArtPickerWindow

A window for choosing one cover from several candidates.

#include "tagkit/CoverArtPickerWindow.h"

Detailed Description

Shown when a lookup turned up cover art on more than one release: a scrollable strip of thumbnails (a CoverArtCandidatesView) with the selected release's title and year underneath, as in Hare's picker. It doesn't block: more covers can be added while it is open, as a lookup finds them.

Use Selected Cover (or double-clicking a thumbnail) sends kMsgCoverArtPickerChosen to the target, with the chosen candidate's "index" (int32) — its position in the vector given to the constructor, and in the order added since — then closes the window.

However the window closes (Use Selected Cover, Cancel, the close box), the target then gets kMsgCoverArtPickerClosed with the window's last frame as "frame" (a BRect), so the program can remember where the user left it and can drop its pointer to the window. Calling Quit() on the window yourself sends nothing. Where the window first opens is up to the program: move it after constructing and before Show(). Needs only be (and the Translation Kit, for decoding the images).
