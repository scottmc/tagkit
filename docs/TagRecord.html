TagRecord

A plain holder for one music file's tags and properties.

#include "tagkit/TagRecord.h"

Detailed Description

TagRecord holds the tag fields TagKit knows how to show and edit, plus a few read-only audio properties. It has no dependency on any tagging library, so records can be passed around freely between threads and between apps.

A record is normally created with its path set and filled in by read_tags(). Edits are made to the fields in memory, modified is set, and write_tags() writes them back.

Unknown numbers are stored as 0 (track, year) or -1 (the audio properties); unknown text is the empty string.

struct MusicBrainzIds

MusicBrainz identifiers to store in a file next to its ordinary tags.

These are written, not read: an empty id leaves whatever the file already holds for it alone, so a record read from a file (which has none of them set) never clears or changes them when it is saved again. write_tags() stores them under the tag names MusicBrainz Picard uses.

FieldTag written
BString discIdMUSICBRAINZ_DISCID
BString releaseIdMUSICBRAINZ_ALBUMID (the release)
BString releaseGroupIdMUSICBRAINZ_RELEASEGROUPID
BString artistIdMUSICBRAINZ_ARTISTID
BString recordingIdMUSICBRAINZ_TRACKID (the recording)

audio_format format_from_extension(const BString& path)

The format implied by a file's extension.

Looks at .mp3, .ogg, .oga, .flac, .opus, .spx, .m4a, .m4b, .mp4, .aac, .wav, .aif, .aiff, .wv, .mpc, .ape, .wma and .tta, ignoring case. Prefer format_from_file() when the file exists.

Parameters

path
A file name or full path.

Returns

The format, or AUDIO_FORMAT_UNKNOWN for any other extension.

audio_format format_from_mime_type(const char* mimeType)

The format for an audio MIME type.

Knows Haiku's type names (audio/mpeg, audio/x-vorbis+ogg, audio/x-opus+ogg, audio/x-flac, audio/x-m4a, audio/x-wav and so on) and the older spellings such as audio/x-mp3 and application/ogg. The comparison ignores case and any ;parameters.

Parameters

mimeType
The MIME type; may be NULL.

Returns

The format, or AUDIO_FORMAT_UNKNOWN for any other type.

audio_format format_from_type_and_name(const char* mimeType, const BString& fileName)

The best guess from a MIME type and a file name.

The MIME type wins. The file name decides when the type is missing or not an audio type (such as application/octet-stream), and when the type only says Ogg but the name says .opus or .spx. It takes the type as a string so a file panel filter, which is handed the type, can use it directly.

Parameters

mimeType
The MIME type; may be NULL.
fileName
A file name or full path.

Returns

The format, or AUDIO_FORMAT_UNKNOWN.

audio_format format_from_file(const BString& path)

The format of a file, from its MIME type and name.

Reads the file's MIME type attribute (asking the system to work it out if the file has none yet) and combines it with the name as format_from_type_and_name() does. This is what lets a file with the wrong or missing extension, or one in a format the extension table doesn't list, still be recognised.

Parameters

path
Full path of an existing file.

Returns

The format, or AUDIO_FORMAT_UNKNOWN if it isn't audio TagKit knows or can't be opened.

bool guess_artist_song_from_file_name(const BString& fileName, BString& artist, BString& song)

A best-effort split of a file name into artist and song.

For example "Artist - Song.mp3" gives ("Artist", "Song"), and "03 - Artist - Song.mp3" gives the same (a leading track number is removed first). It is a starting point for a MusicBrainz search on an untagged file, not a reliable parse.

Parameters

fileName
The file's leaf name.
artist
Set to the guessed artist on success.
song
Set to the guessed song title on success.

Returns

true if a usable separator was found; false (leaving artist and song untouched) if not.
