EmptyArtButton

A button shown in a cover art view while it has no cover.

#include "tagkit/EmptyArtButton.h"

Detailed Description

An icon over a label on a translucent chip, drawn in the middle of the empty cover, such as Hare's “Load CD”. Pressing it posts a message you supply to the view's window. Whether it is shown is up to the program, so it can be hidden and shown again without being set up twice.

CoverArtView and CompactView own one and offer it as SetEmptyButton() and SetEmptyButtonVisible(), so a program rarely uses this class itself. A view of your own can own one and forward Draw(), MouseDown() and MouseUp() to it. In a small square the icon shrinks, and then goes away; the label is shortened to fit.

Documentation

void SetButton(const char* label, BBitmap* icon, BMessage* message)

Sets the label, icon and message.

The icon (NULL for none) is drawn at up to 32 × 32. Takes ownership of icon and message. A NULL message removes the button. The button starts out visible.

void SetVisible(bool visible)

Hides or shows the button.

The button is kept while hidden.

bool IsActive() const

Whether there is a button and it is visible.

void Draw(BView* view, BRect square)

Draws the button centered in a square.

The square is in the view's coordinates and the view's font is used. Does nothing unless IsActive(). Call it after drawing the background.

bool MouseDown(BView* view, BPoint where, BRect square)

Handles a press.

For a primary-button press. Returns true if it landed on the button, which is then tracked until the release.

bool MouseUp(BView* view, BPoint where, BRect square)

Handles the release, posting the message.

Returns true if a press on the button was being tracked. The message is posted to the view's window only if the pointer is still on the button.
