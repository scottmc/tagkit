CoverArtCandidatesView

A strip of thumbnails for choosing between several covers.

#include "tagkit/CoverArtCandidatesView.h"

Detailed Description

Shows a row of thumbnails, with a scroll bar when there are more than fit. Clicking one selects it; double-clicking invokes it. Candidates can be added while the strip is already showing, so covers can appear as they are fetched.

The strip keeps the positions of its candidates in step with the caller's own parallel list: a candidate that didn't decode is given a placeholder slot.

Views never act on the user's behalf themselves. Where something needs to happen (an edit, a menu, a drop), they post a message you give them to the window, with details added; the window decides what to do.

void SetCandidates(BBitmap* const* candidates, int32 count)

Replaces all the candidates.

Takes ownership of every non-NULL bitmap, freeing whatever was shown before, and resets the selection to the first candidate. A NULL entry is a candidate that didn't decode; it still gets a placeholder slot.
