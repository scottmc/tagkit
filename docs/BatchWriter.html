BatchWriter

Saves the tags of many files, reporting after each one.

#include "tagkit/BatchWriter.h"

Detailed Description

write_tags_batch() is write_tags() in a loop with a report. A program that saves a whole list calls it from a worker thread, and its progress function is called after each file, so the program can show “Saved 3 of 12” and stop early. One file that can't be saved never stops the others.

The progress function runs on the thread that called write_tags_batch(). Don't touch views from it; send a message to the window, as TagView does (it sends one message per file and a last one when done, and updates its rows from the window's own thread).

Called after each file, saved or failed.

Parameters

done
How many files have been tried so far, counting this one.
total
How many there are.
result
What happened to this file.
cookie
The value given to write_tags_batch().

Returns

true to carry on, false to stop; the files after this one are left alone.

std::vector<SaveResult> write_tags_batch(const std::vector<TagRecord>& records, save_progress_function progress = NULL, void* cookie = NULL)

Writes each record's tags to its file.

The records are written in order and are not changed; the caller decides what to do with the ones that were saved, usually reading them back with read_tags(). Blocks until done, so call it from a worker thread unless the list is short.

Parameters

records
The files to save.
progress
Called after each file; may be NULL.
cookie
Passed back to progress.

Returns

One SaveResult for every file tried, in the order of records; fewer than records.size() if progress asked to stop.
