TagKit

TagKit

A reusable music-tag library for Haiku programs.

Overview

TagKit is a set of C++ classes with no application-specific wiring: the data model for a music file's tags, reading and writing them with TagLib (MP3, Ogg Vorbis and FLAC), copying them to Haiku file attributes, finding and handling cover art, looking tracks and releases up on MusicBrainz, and a few views for showing it all. It began inside TagView and now has its own repository, so Haiku music programs such as TagView and Hare can share it.

Everything is in the tagkit C++ namespace. The data classes (TagRecord, RecordingMatch) don't depend on any tagging library, so they can be passed freely between threads and apps. TagLib's own types never appear in a header.

Using TagKit in your program

  1. Put this repository in your program's tree, for example as a git submodule named tagkit next to your Makefile. The tagkit.mk file in it lists the source files, libraries and include paths; see its comments for the few lines to add to your Makefile (TAGKIT_SRCS, TAGKIT_LIBS and so on). Or add just the .cpp files you need to SRCS yourself, and make sure the folder holding tagkit is on your include path. Include a header with, for example, #include "tagkit/TagReader.h".
  2. Link the libraries the parts you use need (see the table below). All of them together are LIBS = $(STDCPPLIBS) be tag translation tracker columnlistview musicbrainz5 coverart.
  3. Add TagLib's header folder to SYSTEM_INCLUDE_PATHS. On a 32-bit hybrid system build with setarch x86 so the secondary architecture's headers and libraries are used.
  4. Tell the web services who you are by defining TAGKIT_CLIENT_NAME and TAGKIT_CLIENT_VERSION in DEFINES; see ClientInfo.

Threads

Anything that touches the network (MusicBrainzSearch, CoverArtFetch, ITunesArtwork, HttpFetch) blocks until it is done, so call it from a worker thread and send the result back to your window as a message. Writing tags (TagWriter) does blocking file I/O and should also go on a worker thread for more than a file or two. The views must only be used from their window's thread.

Classes and functions

Data model

TagRecordA plain holder for one music file's tags and properties.
TagFieldNames the seven hand-editable tag fields and converts them to and from text.
RecordingMatchThe results of a MusicBrainz recording search.

Reading and writing

TagReaderReads tags, audio properties and embedded cover art from a file.
TagWriterWrites a record's tags (and cover art) into a file.
TagAttributesCopies tags to Haiku file attributes.

Cover art

CoverArtImageA cover image kept as its original compressed bytes, with helpers to load, convert, export and show it.
CoverArtFetchFinds front covers on the Cover Art Archive.
ITunesArtworkFinds covers through Apple's iTunes Search API.

Web lookups

MusicBrainzSearchSearches MusicBrainz for recordings and releases.
HttpFetchDownloads a URL.
ClientInfoIdentifies the program using TagKit to the web services it calls.

Views

TagViewA BColumnListView that shows TagRecord rows.
CompactViewTags and cover art for one file, in a small rectangle.
CoverArtViewA small square view showing one cover.
CoverArtCandidatesViewA strip of thumbnails for choosing between several covers.
RecordingMatchViewA BColumnListView that shows MusicBrainz recording matches.
OptionalIntegerColumnA column for numbers that may be unknown.

Drag and drop

CoverArtDragDropDrag and drop of a whole cover image.
EmptyArtButtonA button shown in a cover art view while it has no cover.

Utilities

GenreListThe genre names, for drop-down menus.
