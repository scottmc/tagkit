CoverArtDragDrop

Drag and drop of a whole cover image.

#include "tagkit/CoverArtDragDrop.h"

Detailed Description

Shared by CoverArtView and CompactView, so both behave the same way, much like the image in ShowImage. Only the whole image is dragged or dropped.

Dragging out: pressing on the image and moving starts a drag of a thumbnail. A target that wants the image asks for it (B_COPY_TARGET) and gets it as the image's own format, or as PNG if it asks for that.

Dropping in: an image file dragged from Tracker, or an image offered by another application, becomes a copy of the drop message with the image added.

A view that has its own cover (or none) forwards the mouse events and messages to this class.

Documentation

void SetDragMessage(BMessage* message)

Sets the message dragged out.

It should be a B_SIMPLE_DATA message. NULL means nothing can be dragged out. Takes ownership.

void SetDropMessage(BMessage* message)

Sets the message posted on a drop.

Posted, as a copy with the dropped image added, to the view's window when an image is dropped on the view. Takes ownership.
