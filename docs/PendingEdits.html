PendingEdits

Remembers hand edits to rows until they are applied or discarded.

#include "tagkit/PendingEdits.h"

Detailed Description

Keeps track of hand edits to the tags of rows in a list, from the moment they are made until the user either keeps them (Apply) or takes them back (Discard Changes): each row's record as it was before its first edit is remembered, so the edit can be undone.

The rows belong to the program, whatever kind it uses (a TagView's rows, Hare's rows), so the class only knows them as opaque pointers and asks an EditHost to read and show their records. It does no drawing and has no windows; the program decides when to call it (from a FieldEditorWindow's result, say) and keeps its Apply and Discard buttons in step with HasPending(). Needs only be.

EditHost

What PendingEdits needs from the program that owns the rows. Derive from it and implement:

bool EditRowExists(void* row)
Whether the row is still in the list (it may have been removed while an editor was open).
TagRecord EditRowRecord(void* row)
The record the row currently shows.
void EditSetRowRecord(void* row, const TagRecord& record)
Makes the row show the record, and hold it, so it is what gets saved.

int32 SetField(const std::vector<void*>& rows, tag_field field, const BString& value)

Sets a field in several rows.

Sets the field in every one of rows that still exists, marking their records modified and remembering how each row was before its first edit. A row the value would not change is left alone.

Returns

How many rows changed, or -1 if the value isn't acceptable for the field (see set_tag_field_value()), in which case nothing was changed.
