CompactView

Tags and cover art for one file, in a small rectangle.

#include "tagkit/CompactView.h"

Detailed Description

An outlined rectangle holding two squares: the tag fields on the left (each name in bold, then its value, one per row) and the cover art on the right (a blue gradient when there is none). Everything scales with the window. The file's name is shown under the squares, inside the outline.

A value too long for its row wraps onto one extra line, and is cut off with an ellipsis if that isn't enough. When the wrapped rows don't fit, the text shrinks until they do. SetTextScale() makes the text larger or smaller.

Views never act on the user's behalf themselves. Where something needs to happen (an edit, a menu, a drop), they post a message you give them to the window, with details added; the window decides what to do.

A CompactView in a small window, at text size 2: the tag fields on the left, the cover art on the right, and the file's name under them.

The same view in a much larger window. Everything scales with the window, so it can also be used as a larger display. A value too long for its row wraps onto one extra line.

Documentation

CompactView(const char* name)

Creates the view.

void SetRecords(const std::vector<const TagRecord*>& records)

Shows several records at once, for a multiple selection.

Each field shows the value all the records share, or “(multiple)” where they differ. Duration is left out, and Format is shown only when every record has the same one. “N files selected” replaces the file name. One record is shown as SetRecord() would show it; none shows the empty state. Right-clicking a row still posts the edit message; the app decides what to do with it for each file.

Parameters

records
The records (copied).

void SetRecord(const TagRecord* record)

Shows a record's tag fields.

The record is copied, so it needn't outlive the call. NULL shows an empty “No file selected” state.

void SetShowDuration(bool show)

Shows or hides the Duration row.

Shown by default. Hiding it leaves more room for the other rows, whose text then grows. With several files selected Duration is never shown.

void SetShowFormat(bool show)

Shows or hides the Format row.

Shown by default. With several files selected it is shown only when they all share a format.

void SetInfoWidthRatio(float ratio)

Makes the tag square wider than the cover art.

The ratio of the tag square's width to the cover art's side, limited to 1.0–2.0. The default, 1.0, is two equal squares. A wider square lets long values stay on one line.

float InfoWidthRatio() const

The current ratio.

void SetMinimumViewSize(float width, float height)

Sets the smallest size the view asks its layout for.

The default is 300 × 150; the least accepted is 100 × 60. The text shrinks to fit, down to a lower limit, so very small sizes cut values off.

void SetCoverBitmap(BBitmap* bitmap)

Sets the cover art shown.

Takes ownership of the bitmap (NULL shows the blue gradient), freeing whatever was shown before.

void SetTextScale(float scale)

Makes the text larger or smaller than its automatic size.

The automatic size scales with the square. scale is limited to 0.5–2.0; the default is 1.0.

float TextScale() const

The current text scale.

void SetCoverDragMessage(BMessage* message)

Sets the message dragged out of the art square.

NULL means it is not draggable. See CoverArtDragDrop. The view takes ownership.

void SetCoverDropMessage(BMessage* message)

Sets the message posted when an image is dropped on the art square.

Posted to the window with the dropped image added. The view takes ownership.

void SetCoverContextMessage(BMessage* message)

Sets the message posted when the art square is right-clicked.

Posted to the window with the pointer's screen position added as "where" (a BPoint). The view takes ownership.

void SetEditMessage(BMessage* message)

Sets the message posted when a tag row is right-clicked.

Posted for the Artist, Title, Album, Track, Year, Genre or Comment row. The copy carries "field" (int32, a tag_field), "where" (BPoint, the screen position) and "width" (float, the tag square's width). The view takes ownership.
