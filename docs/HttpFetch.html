HttpFetch

Downloads a URL.

#include "tagkit/HttpFetch.h"

Detailed Description

Downloading uses the curl command that ships with Haiku, because Haiku's own HTTP request headers are private. The request is sent with the User-Agent of the calling program.

A request gives up when no connection is made within 10 seconds, when the transfer stalls (under one byte a second for 15 seconds), or when it has taken the whole time limit, which is network_timeout() unless a call asks for another.

BString url_encode(const BString& text)

Percent-encodes text for use in a URL's query.

Everything but letters, digits and - _ . ~ becomes %XX (the bytes of UTF-8 characters included; a space becomes %20). Use it on each value you put after a ?.

Parameters

text
The text to encode.

Returns

The encoded text.

status_t http_get(const BString& url, std::vector<unsigned char>& data, BString* errorMessage = NULL, int32 timeoutSeconds = 0, int32* httpStatus = NULL)

Downloads a URL into a buffer.

Blocks until done, so call it from a worker thread, never the UI thread.

Parameters

url
The address to fetch.
data
Replaced by the downloaded bytes.
errorMessage
If not NULL, receives a short reason on failure.
timeoutSeconds
The most time the whole request may take; 0 uses network_timeout().
httpStatus
If not NULL, receives the final HTTP status (for example 404), or 0 when there was no answer at all.

Returns

B_OK only for a successful (2xx) response; otherwise an error: B_TIMED_OUT if a time limit ran out (the message is then "timed out"), B_BUSY if the server said "too many requests" (HTTP 429 or 503; wait a moment and try again), or B_ERROR (for an HTTP error the message reads like "HTTP 404").
