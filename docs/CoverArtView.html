CoverArtView

A small square view showing one cover.

#include "tagkit/CoverArtView.h"

Detailed Description

Shows one cover image, or a placeholder when there is none. The whole image can be dragged out and an image can be dropped onto it (see CoverArtDragDrop), and right-clicking it posts a message so the window can open a context menu.

Views never act on the user's behalf themselves. Where something needs to happen (an edit, a menu, a drop), they post a message you give them to the window, with details added; the window decides what to do.

A CoverArtView under the list showing a cover that has been chosen but not yet saved to the file.

Documentation

CoverArtView(const char* name, float size = 112.0f)

Creates the view.

The view is a square of size pixels.

void SetBitmap(BBitmap* bitmap)

Sets the image shown.

Takes ownership of the bitmap (NULL shows the placeholder), freeing whatever was shown before.

void Clear()

Shows the placeholder.

void SetDragMessage(BMessage* message)

Sets the message dragged out of the view.

NULL means not draggable. The view takes ownership.

void SetDropMessage(BMessage* message)

Sets the message posted when an image is dropped on the view.

Posted to the window with the dropped image added. The view takes ownership.

void SetEmptyButton(const char* label, BBitmap* icon, BMessage* message)

Sets a button shown while there is no cover.

An icon over a label on a translucent chip, drawn in the middle of the empty view, for something like “Load CD”. Pressing it posts message to the window. Takes ownership of icon (NULL for none) and message; a NULL message removes the button. It starts out visible. See EmptyArtButton.

void SetEmptyButtonVisible(bool visible)

Hides or shows that button.

For a program that only wants the button at times (Hare shows Load CD only while a CD is mounted).

void SetContextMessage(BMessage* message)

Sets the message posted when the view is right-clicked.

Posted to the window with the pointer's screen position added as "where" (a BPoint). The view takes ownership.
