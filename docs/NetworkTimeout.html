NetworkTimeout

The time limit for TagKit's network requests.

#include "tagkit/NetworkTimeout.h"

Detailed Description

Downloads (http_get(), and so the Cover Art Archive and iTunes lookups) have a time limit, 30 seconds unless the program sets another with set_network_timeout(). It is handed to the curl command that does the download.

The MusicBrainz search is the exception: libmusicbrainz5 has no way to set a time limit, so MusicBrainzSearch is not covered.

The lookups report a time-out through an optional bool* (timedOut), so a program can say "timed out" instead of "nothing found".
