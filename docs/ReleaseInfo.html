ReleaseInfo

One MusicBrainz release as a lookup returns it, with a track list.

#include "tagkit/ReleaseInfo.h"

Detailed Description

The answer of LookupDiscId(), LookupRelease() and LookupDisc(). Like RecordingMatch these are plain holders with no dependency on any JSON or web code.
