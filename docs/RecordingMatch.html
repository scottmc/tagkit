RecordingMatch

The results of a MusicBrainz recording search.

#include "tagkit/RecordingMatch.h"

Detailed Description

A RecordingMatch is one candidate recording returned by MusicBrainzSearch::SearchRecording(). Each lists the releases (albums, singles, ...) the recording appears on as ReleaseRefs. Cover art is looked up per release, so a recording on several releases gives the user several candidate covers to choose from.
