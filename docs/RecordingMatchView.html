RecordingMatchView

A BColumnListView that shows MusicBrainz recording matches.

#include "tagkit/RecordingMatchView.h"

Detailed Description

Lists the RecordingMatches from a search so the user can pick one. Each row is a RecordingMatchRow, which keeps a copy of its match.

A RecordingMatchView listing the matches for a search, sorted by how close each length is to the file's.
