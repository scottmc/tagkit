TagKitStrings

How TagKit's own words get translated.

#include "tagkit/TagKitStrings.h"

Detailed Description

TagKit's own words — column titles, field names, buttons, window titles, the “(multiple)” shown for files that disagree — are English by default, and nothing needs any library for that. A program that has a Haiku catalog (a Locale Kit one) defines TAGKIT_USE_CATALOG when it builds, in DEFINES next to the TAGKIT_CLIENT_* ones:

DEFINES = TAGKIT_CLIENT_NAME=MyApp TAGKIT_CLIENT_VERSION=1.0 \
	TAGKIT_USE_CATALOG

Every string in TagKit then goes through B_TRANSLATE_CONTEXT() with the context "TagKit":

  • The program's own catalog is searched for them at run time, so there is nothing to set up in the code; only the catalog.
  • Haiku's catkeys collection (make catkeys) finds them in TagKit's source files just as it does the program's own, because TagKit is compiled into the program. They land in the program's .catkeys file under the context TagKit.
  • A string without a translation is shown in English.

Words a program gives TagKit itself, such as an EmptyArtButton's label, are the program's to translate. The genre names are not translated, and neither are the audio format names.

Messages with something in them have a %placeholder% replaced with the value after translating (“Edit %field%”, “Cover art for "%file%"”), and counts use ICU plural rules ({0, plural, one{# file selected} other{# files selected}}), which a translator can adapt to the language's own plural forms.

Documentation

TAGKIT_TR(text)

Marks and translates a string.

With TAGKIT_USE_CATALOG it is B_TRANSLATE_CONTEXT(text, "TagKit"); without it, just the text. Call it where the string is used, not for a global or static, so the translation is looked up after the program's catalog is loaded.

BString fill_in(const char* text, const char* placeholder, const char* value)

Replaces a placeholder in a translated text.

Returns

text with the first placeholder (such as "%field%") replaced by value.

BString files_selected_text(int32 count)

“3 files selected” in the program's language.

Uses the plural rules of the language when TAGKIT_USE_CATALOG is defined; otherwise English.
