ClientInfo

Identifies the program using TagKit to the web services it calls.

#include "tagkit/ClientInfo.h"

Detailed Description

MusicBrainz, the Cover Art Archive and iTunes ask every program that calls them to say who it is. TagKit sends the calling program's name and version as the HTTP User-Agent. The program supplies them in its Makefile, as preprocessor definitions written without quotes:

DEFINES = TAGKIT_CLIENT_NAME=MyApp TAGKIT_CLIENT_VERSION=1.0 \
	TAGKIT_CLIENT_CONTACT=example.org/myapp
DefinitionMeaning
TAGKIT_CLIENT_NAMEThe program's name. Required.
TAGKIT_CLIENT_VERSIONThe program's version. Required.
TAGKIT_CLIENT_CONTACTA web address or e-mail address for the program. Optional.

The resulting User-Agent looks like MyApp/1.0 ( example.org/myapp ). If the name or version is missing, the compiler prints a warning, the program identifies itself as UnknownClient/0, and a warning is written once to stderr at run time.
