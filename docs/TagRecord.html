TagRecord

A plain holder for one music file's tags and properties.

#include "tagkit/TagRecord.h"

Detailed Description

TagRecord holds the tag fields TagKit knows how to show and edit, plus a few read-only audio properties. It has no dependency on any tagging library, so records can be passed around freely between threads and between apps.

A record is normally created with its path set and filled in by read_tags(). Edits are made to the fields in memory, modified is set, and write_tags() writes them back.

Unknown numbers are stored as 0 (track, year) or -1 (the audio properties); unknown text is the empty string.

bool guess_artist_song_from_file_name(const BString& fileName, BString& artist, BString& song)

A best-effort split of a file name into artist and song.

For example "Artist - Song.mp3" gives ("Artist", "Song"), and "03 - Artist - Song.mp3" gives the same (a leading track number is removed first). It is a starting point for a MusicBrainz search on an untagged file, not a reliable parse.

Parameters

fileName
The file's leaf name.
artist
Set to the guessed artist on success.
song
Set to the guessed song title on success.

Returns

true if a usable separator was found; false (leaving artist and song untouched) if not.
