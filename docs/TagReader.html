TagReader

Reads tags, audio properties and embedded cover art from a file.

#include "tagkit/TagReader.h"

Detailed Description

These functions use TagLib, but TagLib's types stay private to the implementation: nothing in the header depends on it. Reading touches only the file's headers and tags, so it is quick enough for the occasional file on the UI thread; for a large batch, use a worker thread.

bool read_tags(TagRecord& record)

Fills a record from the file it names.

Sets artist, title, album, genre, comment, track and year, and the audio properties (duration, bit rate, sample rate, channels), from the file at record.path, then sets record.tagsLoaded. Fields the file has no value for keep their TagRecord defaults. path, fileName and format are inputs and are left alone.

Parameters

record
The record to fill; path must be set.

Returns

false (leaving the record untouched) if the file couldn't be opened or TagLib doesn't recognize it as audio; otherwise true.

bool read_cover_art(const BString& path, CoverArtImage& image)

Reads the picture embedded in a file.

Gives the front cover if there is one, otherwise the first picture. Only the image bytes and MIME type are filled in; the image isn't tied to any MusicBrainz release.

Parameters

path
The audio file.
image
Receives the picture.

Returns

false if the file can't be read or has no usable picture.
