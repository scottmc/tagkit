CoverArtImage

A cover image kept as its original compressed bytes, with helpers to load, convert, export and show it.

#include "tagkit/CoverArtImage.h"

Detailed Description

A CoverArtImage keeps the image exactly as it was found (JPEG, PNG or GIF bytes), so the same image can be shown, exported and embedded in an audio file unchanged. Images in other formats are converted to PNG when loaded. The conversion and display functions use the Translation Kit.

BString image_extension_for_mime_type(const char* mimeType)

A file extension for an image MIME type.

Gives the extension (without the dot) that other systems recognise: image/jpeg → jpg, image/png → png, image/bmp → bmp, image/tiff → tif, and so on. Falls back to the MIME subtype (without an x-).

Parameters

Returns

Reads an image file into an image.

status_t write_cover_file(const CoverArtImage& image, const char* directory, const char* mimeType = NULL, bool overwrite = false, BString* writtenPath = NULL, BString* errorMessage = NULL)

Saves the image as cover.<ext> in a folder.

The format is mimeType (for example image/png), or the image's own when that is NULL or empty; if the image can't be converted it is saved as it is. A cover file already there is left alone (B_FILE_EXISTS) unless overwrite is true, so calling this once per track of an album writes it only once. The file's MIME type is set, and writtenPath is set to its path when a file was written.
