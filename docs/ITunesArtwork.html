ITunesArtwork

Finds covers through Apple's iTunes Search API.

#include "tagkit/ITunesArtwork.h"

Detailed Description

Used as a fallback when the Cover Art Archive has few covers. Downloads go through http_get().

int32 fetch_itunes_cover_art(const BString& artist, const BString& album, int32 maxImages, const CoverArtFoundFunction& found)

Searches iTunes for albums and downloads their covers.

Searches for albums by artist (and album, if not empty), keeps the ones whose artist matches (those whose title matches album first), and downloads their covers, calling found() for each as it arrives — the same progressive style as fetch_cover_art().

Each image's releaseTitle reads "<album> (iTunes)" and its releaseId is "itunes:<collection id>".

Performs network I/O: call it from a worker thread.

Parameters

artist
The artist.
album
The album; may be empty.
maxImages
The most covers to return.
found
Called with each cover.

Returns

How many covers were found, at most maxImages.
