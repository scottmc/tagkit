FieldEditorWindow

A small window for editing one field where it was right-clicked.

#include "tagkit/FieldEditorWindow.h"

Detailed Description

Opened where the user right-clicked a tag field (in a CompactView or a TagView), with one text field. Return, or clicking anywhere else, accepts the text; Escape cancels.

With a list of choices (the genre list, say) the text field is replaced by a drop-down menu: picking an entry accepts it straight away. Recently picked choices, if given, come first, set off from the full list by a line. (none) at the top clears the value, and a current value that isn't in the list is kept as an entry of its own, so opening the editor never loses it. Other… at the bottom turns the menu into a text field for a value that isn't in the list.

When the value stands for several files that don't agree (mixed), the editor starts out blank. Clicking elsewhere with nothing typed then cancels instead of accepting a blank, so a stray click can't clear the field of every file; Return in the blank field, or picking (none), still does.

Accepting sends a copy of the message given to the constructor to the target, with the text added as "value"; put whatever is needed to find the way back (which row, which field) in that message. Cancelling sends nothing. Either way, once the window is gone it sends kMsgFieldEditorClosed (with the window as "editor") so the caller can drop its pointer. Needs only be.

The drop-down's entries, or NULL for a text field.

Entries to list first, newest first, or NULL.
mixed
true if the value stands for several files that differ; see above.

Call Show() to open it.

FieldEditorWindow* new_field_editor(BMessenger target, const BMessage& result, tag_field field, const std::vector<const TagRecord*>& records, BPoint screenPosition, float width, const std::vector<BString>* recentGenres = NULL)

Makes the editor for one field of one or more files.

What a program does when the user right-clicks a field. It fills in the label, the current value (blank, with mixed set, if the files disagree), the drop-down of genres for the Genre field, and the mixed flag, so every program using it behaves the same. recentGenres (may be NULL) heads the genre menu. Call Show() on the result.
